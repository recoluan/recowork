# Archive Index

## Conclusion First

This location holds historical material that is no longer a default learning source. The learning workspace and unit indexes keep Current content only; use this index to trace history by category, topic, and version. Get learner confirmation before archival; never automatically move, delete, or rewrite learner files.

## Body

### Usage Rules

- Use `archive/<category>/<topic>/v<major>.<minor>.md`; for example, `archive/02-lessons-and-practice/prompting-basics/v1.0.md`.
- An archive document must be `Superseded` or `Archived`, with a relative link to its Current learning record or a stated archival reason.
- Create category and topic directories only after something is archived. Do not pre-create empty directories or duplicate current lesson bodies.

### Categories

_Empty at initialization. Add category, topic, version, status, and a one-line summary after archival occurs._
