# Project Fact Map

Maintain each fact in one place; elsewhere link or give a brief attributed summary. Create missing documents when needed; this map is not an initialization checklist.

| Fact | Authoritative location |
| --- | --- |
| Exploration problem, candidates, hypotheses, direction confirmation and accepted risks | `01-exploration-and-validation/direction-decision-package.md` |
| Stable background, problem, goals, non-goals and overall constraints | `project-brief.md`; link detailed scope rather than duplicating it |
| Current stage, actual progress, next step and action status | `04-plan-and-decisions/delivery-plan.md`, also during exploration |
| Unresolved questions, impact and closure evidence | `open-questions.md`; closed entries retain a short decision link, never remain open |
| Restartable inactive directions | `parked-ideas.md`, with reason and restart condition, outside active scope |
| Current requirements, design and boundaries | Existing topics in `02-requirements-and-constraints/` and `03-solution-design/` |
| Small / important durable decisions | In the topic / `04-plan-and-decisions/decision-records/`, with stable IDs for important decisions |
| Validation results, limitations and reproducible evidence | Exploration topic or `06-review-and-validation/`; the plan links results |

The [home](../workspace/index.md) provides a five-minute return route, not independently maintained facts. Decisions preserve reasons at the time; designs state today's applicable conclusions, distinguished by scope and supersession. Synchronization follows the [freshness standard](./artifact-freshness-standard.md).
