# Scenarios

- Explain a term in conversation; update an existing topic only if project conclusions change.
- Add a small conclusion and its reason to the existing design section, not a supplement file.
- Keep a simple design as one topic file in `03-solution-design/`, linked by its parent. Split only independently useful interfaces or reproducible experiments.
- When preset candidates and local storage are confirmed, close the corresponding input, AI strategy and persistence questions and check design and next steps; appending a decision alone is insufficient.
- Return through the home and current topic; an older stress test can remain dated, scoped evidence without an absorbed review draft becoming current design authority.

See the [fact map](./knowledge-structure.md) for stage paths and the [workflow](./workflow.md) for authority.
