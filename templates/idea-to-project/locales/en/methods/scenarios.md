# Scenarios

Use this template when a project needs planning, technical assessment, decision tracking, and durable AI collaboration.

## Planning And Solution Design

Use the generated `workspace/` directory to separate formal outputs from thinking traces:

- Put project background, goals, scope, and current status in `project-brief.md`.
- Before direction confirmation, put the problem, candidate directions, brainstorms, assumptions, validation, and direction decision package in `01-exploration-and-validation/`.
- After direction confirmation, put requirements, user scenarios, constraints, and clarifications in `02-requirements-and-constraints/`.
- Put tradeoff analysis, feasibility, architecture, and technical plans in `03-solution-design/`.
- Put phases, milestones, delivery plans, and durable decisions in `04-plan-and-decisions/`.
- Put active brainstorming, intermediate reasoning, and discussion summaries in `05-thinking-traces/`; completed material enters `archive/` under the standard.
- Put review, validation, and acceptance notes in `06-review-and-validation/`.
- Track questions that require user confirmation in `open-questions.md`.

## Rule

Do not collapse everything into one large document. Keep `index.md` files updated so humans and AI agents can read only the Current context; historical versions are entered only through `archive/index.md`.
