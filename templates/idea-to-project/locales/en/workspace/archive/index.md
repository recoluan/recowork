This location holds historical material that is no longer a default source. The formal workspace and its section indexes keep Current content only; when traceability is needed, navigate from here by category, topic, and version.

## Usage Rules

- Use `archive/<category>/<topic>/v<major>.<minor>.md`; for example, `archive/03-solution-design/sign-in-approach/v1.0.md`.
- An archive document must be `Superseded` or `Archived`, with a relative link to its Current replacement or a reason for archival.
- Get user confirmation before archival; never automatically move, delete, or rewrite user documents.
- Add category and topic entries only when material is archived. Do not pre-create empty directories or duplicate formal bodies here.
