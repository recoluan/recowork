# 从想法到落地工作流包

先探索与验证，明确确认方向和进入项目后，再推进需求、设计、实施与验收。核心阶段门和重要决策追溯保留。

从 [工作空间首页](./工作空间/index.md) 回读背景、确认结论、进展、未解问题与下一步。新空间只生成六份工作记录及现有工作方法；主题、证据、阶段子目录与归档按需增加，简单主题一篇文件即可。答疑可以只留在对话，改变项目事实时优先更新已有主题。

职责与路径见 [事实地图](./工作方法/知识结构.md)，维护授权见 [工作流程](./工作方法/工作流程.md)。

已有空间：升级只安全更新未修改的工作方法和目标文件；已有工作空间不会被覆盖、搬迁或删除。新规则用于后续工作，首页与事实分工需在用户授权范围内人工合并；不要重新初始化现有目录。
