# 从想法到落地工作流包

这个包让用户只选择一次工作流，随后按阶段推进：先探索与验证，再由用户明确确认进入项目阶段。它不把脑暴伪装成项目结论，也不在方向未确认时过早生成完整方案、计划或实施改动。

适合场景：

- 只有模糊想法、几个候选方向，或已经准备启动一个项目。
- 希望让 AI 区分事实、假设、证据与待确认问题。
- 希望确认方向后自然进入需求、方案、计划、决策和验收。

核心交付：

- `AGENTS.md`
- `工作方法/`：阶段判断、确认门、文档规范、质量门禁和产物保鲜规则。
- `工作空间/`：统一保存探索和项目推进的当前事实。
- `01-探索与验证/方向决策包.md`：问题、候选方向、证据、关键假设、风险和进入项目建议。
- `项目简报.md`、`待确认问题.md`：进入项目后持续维护的权威上下文。
- `02-需求与约束/` 至 `06-评审验证/`：仅在用户确认进入项目后成为主要工作区域。
