# 项目事实地图

每类事实只在下列位置维护，其他地方用链接或注明来源的短摘要。不存在的文档按需创建，不把路径地图当作初始化清单。

| 事实 | 权威维护位置 |
| --- | --- |
| 探索中的问题、候选、假设、方向确认与接受风险 | `01-探索与验证/方向决策包.md` |
| 稳定背景、问题、目标、非目标和总体约束 | `项目简报.md`；具体需求范围链接主题，不重复逐项维护 |
| 当前阶段、实际进展、下一步与行动状态 | `04-计划与决策/阶段划分与推进路径.md`，探索阶段也使用 |
| 尚未解决的问题、影响和关闭依据 | `待确认问题.md`；关闭项只留简短结论链接，不继续列为待确认 |
| 暂不推进但可重启的方向 | `搁置想法.md`，保留原因和重启条件，不混入活动范围 |
| 需求、设计的当前结论与边界 | `02-需求与约束/`、`03-方案设计/` 内已有主题 |
| 小决策 / 重要且需长期追溯的决策 | 主题内 / `04-计划与决策/决策记录/`，重要决策使用稳定编号 |
| 验证结果、局限和复现证据 | 探索期相关主题或 `06-评审验证/`；计划只引用结果 |

[首页](../工作空间/index.md) 提供五分钟回读路线，不能自行维护不同版本的事实。决策记录保存当时理由；当前方案保存今天有效的结论，以作用域和替代关系区分二者。同步步骤见 [产物保鲜规范](./产物保鲜规范.md)。
