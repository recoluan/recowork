# 产物保鲜规范

## 状态与当前依据

使用 `草稿`、`评审中`、`当前有效`、`已替代`、`已归档`。草稿与评审材料不能冒充已确认事实；同一主题和作用域只有一个当前默认来源。旧“定稿”按实际有效性复核，不靠改标签宣布确认。

## 事实同步

决策确认或验证改变结论后，在同一轮工作中：

1. 按 [事实地图](./知识结构.md) 更新真正受影响的需求、设计或行动；重要决策保留确认依据与理由，小决策留在主题内。
2. 按问题内容而非仅文件链接匹配 `待确认问题.md`，关闭已解决项并链接决定；未解决部分保留边界，不因相关决策存在就全部关闭。
3. 更新推进路径中的进展和下一步，链接验证证据；只有背景或目标变化才改项目简报。
4. 检查首页摘要与来源、父级导航、相关当前结论是否一致。若依据冲突或确认缺失，明确标为待核实，不能用流畅摘要掩盖它。

## 历史保留与阅读分离

已吸收、被替代或已结束材料标注状态及当前结论去向，退出默认阅读路径；仍用于复现或支撑当前判断的证据可以继续被当前主题引用，注明时间和适用范围。重要决策、里程碑和复现证据保留，日常编辑不制造快照。

历史可以原地保留：从正常索引移除，在既有索引的独立“历史（非当前依据）”区链接，并注明替代去向；默认不读取历史区；需要与正常入口完全分离时，按需创建归档索引链接原地材料。查看器禁用原始 HTML，不依赖 HTML 折叠生效。无需先搬文件才能改善导航，也不新增归档候选清单。

确有物理归档需要时才创建 `工作空间/归档/index.md` 及所需分类，按分类、主题、版本保存有意义的快照，保留相对引用；不预建空分类。移动、重写、删除和批量整理权限统一遵循 [工作流程](./工作流程.md)。历史原地隐藏不等于查看器搜索自动排除，搜索命中仍须核对状态与来源。

每次实质工作只检查受影响的事实链，不要求全库整理。
