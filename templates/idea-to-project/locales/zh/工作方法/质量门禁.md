# 质量门禁

## 可信（内容评审）

- 阶段与业务确认有依据吗？结果是否满足已授权目标，验证是否区分通过、未测与未验收？
- 对照决策和验证证据，受影响的需求、设计、待确认项与下一步是否一致？部分解决是否保留剩余问题？
- 当前结论的作用域、限制和来源清楚吗？关键决策理由、替代关系及复现证据仍可追溯吗？

## 好读（回读评审）

模拟用户两周后返回：能否在五分钟内从首页知道要解决什么、已确认什么、做到哪、未解问题、下一步和应该读哪篇？沿链接实际打开当前主题，检查父入口是否漏模块、历史是否冒充当前依据。

按 [文档规范](./文档规范.md) 检查：答疑可不落盘，小结论优先原地更新，简单主题不用目录加双文档，复杂主题仍可独立提供接口、验收或复现证据。

链接存在、相对路径和导航可达可自动检查；事实一致性、拆分必要性、确认充分性和五分钟理解必须由 Agent 与读者内容评审，不能宣称链接检查证明语义正确。无需为每次自检另建报告。
