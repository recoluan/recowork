可重启的搁置想法

开发中

不等同于归档

从想法到落地工作空间会新增搁置想法清单，记录暂不推进但未来可重启的方向，不再让它们埋在过程记录、待确认问题或历史归档里。

可扫描、可重启

每一项会记录搁置原因、重启条件、优先级、最后评估、关联材料和下一步；当条件满足或用户再次提起时，可以直接重新评估。

聊天也能续接

Chat / Mobile 不创建本地文件，但启动指令和续接摘要会保留搁置方向与重启条件，便于下一次对话恢复判断。

2026-08-18

3.1.0

已发布

当前内容保持精简

持续工作空间的正式目录和常规索引只保留当前有效或仍待处理的内容，避免历史版本与当前事实并列造成误读。

历史统一归档

确认保留的历史版本和已结束过程材料会按分类、主题和版本进入独立归档；日常编辑仍直接更新当前文档。

用户始终控制文件

RecoWork 不会自动移动、归档、删除、重命名或重写已有文件。Agent 会先给出候选、理由、目标位置与替代文档，等待确认后再处理。

2026-08-16

3.0.0

已发布

初始化入口

网站生成的本地 Agent Prompt、README 和初始化 Prompt 统一使用 npx --yes recowork@latest。首次使用会临时获取 npm 包，无需预先全局安装 rw，也不会停在 npm 的交互式安装确认。

统一工作流

想法探索与项目工程化合并为“从想法到落地”：探索、验证、明确立项和项目推进在同一套阶段式工作流中完成；中文模板名称同时更新为“从想法到落地”和“系统性学习”。

破坏性变更与迁移

不再支持将 idea-engineering 与 project-engineering 作为独立模板使用；新建请使用 idea-to-project，idea 和 project 别名仍可用。已有工作区不会被改写，rw status 与 rw upgrade 只会给出在新目录初始化统一工作流的迁移指引。

2026-07-24

2.0.0

已发布

新增与变更

  • 新增网页设计规范模板：本地 Agent 生成一份可复用规范，聊天 / 手机端提供可独立复制的响应式网页大 Prompt。
  • 本地初始化会安全集成到已有根目录 AGENTS.md，仅管理 RecoWork 标记区块；升级会保留用户修改或删除过的区块。
  • 工作流要求 AI 客观指出风险与替代方案。
  • 下线日常任务协作模板；新初始化请选想法、项目或学习工作流。已有 general 工作流不被改写，运行 rw status 或 rw upgrade 会得到只读迁移指引。

兼容性

已有根目录 AGENTS.md 在 RecoWork 受管区块之外的内容不会被改写。日常任务模板及其别名不再支持新建；已有 general 工作流保持不动，只通过 rw status 或 rw upgrade 提供迁移建议。

破坏性变更

不再支持初始化、列出或查看 general-ai-workflow 及其 general、task、daily 别名。请改用想法、项目或学习工作流；已有 general 工作流不会被改写。

2026-07-21

1.0.0

已发布

新增与变更

  • RecoWork 收敛为聊天 / 手机端与电脑端 AI 助手两种使用环境。
  • 本地环境生成 AGENTS.md、工作方法和工作空间；聊天环境只生成启动、执行与续接/迁移三件套。
  • 长期结论写入工作空间的权威文档与索引，初始化不会覆盖已有 RecoWork 工作流。

破坏性变更与迁移

品牌专属 target、原生 skill、平台配置目录和 Notion/飞书导出已移除。旧命令保留别名；旧 Chat 工作流执行 rw status 或 rw upgrade 时会得到创建独立本地目录的迁移指引。
