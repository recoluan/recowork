它到底做什么

先把工作方式交给 Agent，再让它开始做事。

RecoWork 不替换模型，也不在后台运行 Agent。它让 Agent 知道该遵守什么规则、如何组织产物、怎样检查结果，以及下一次如何继续。

01任务与边界

明确要完成什么、不做什么，以及下一步。

02标准与审查

把完成条件、检查和人工判断写进要求。

03当前事实与续接

下一次从已确认状态继续，不再重讲背景。

  • 不托管模型或 API Key。
