它到底做什么

先把工作方式交给 Agent，再让它开始做事。

RecoWork 不替换模型，也不在后台运行 Agent。它让 Agent 知道该遵守什么规则、如何组织产物、怎样检查结果，以及下一次如何继续。

01任务与边界

明确要完成什么、不做什么，以及下一步。

02标准与审查

把完成条件、检查和人工判断写进要求。

03当前事实与续接

下一次从已确认状态继续，不再重讲背景。

本地工作流初始化完成后，RecoWork 会把项目简报、待确认问题、当前进度和归档组织为可阅读的本地查看器。它只读，不会重新生成或修改你的文件。

01

直接让 Agent 打开

在当前项目中告诉本地 Agent“打开 RecoWork 工作空间”。它会识别目录、启动或复用查看器，并告诉你本地地址。

02

也可自行运行

在项目根目录运行 npx 命令即可。无需全局安装；同一工作空间已打开时会直接复用。

控制权仍在你

AI 负责推进工作，你负责判断与确认。

  • 不托管模型或 API Key。
  • 本地文件保存在你选择的位置。
  • AI 的建议、产出和修改仍由你审查。
  • 不承诺后台执行、自动记忆或无限自动化。
